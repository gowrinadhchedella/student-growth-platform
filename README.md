# 🎓 Student Growth Platform – Telangana

An interactive, responsive web application designed to track student learning analytics, course module progress, quiz performances, and gamified study streaks for students across Telangana.

🚀 **Live Demo:** [Launch Live Application](https://gowrinadhchedella.github.io/student-growth-platform/)

---

## Key Features

- 📊 **Interactive Analytics:** Real-time visual progress tracking and subject weak-area identification powered by Chart.js.
- 📚 **Comprehensive Curriculum:** Standardized subject modules across Mathematics, Science, History, and English.
- 📝 **Adaptive Quiz Engine:** Instant evaluation, automated scoring, and detailed explanation breakdowns.
- 🏆 **Gamification Framework:** Daily streaks, XP points system, unlockable achievement badges, and local leaderboards.
- 💾 **Client-Side Persistence:** Seamless state management utilizing HTML5 Web Storage APIs (`localStorage`).

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3 (CSS Variables, Flexbox, CSS Grid)
* **Logic:** Vanilla JavaScript (ES6+)
* **Data Visualization:** Chart.js
* **Hosting:** GitHub Pages
